# 가계부

브라우저에서 바로 쓰는 1인용 가계부입니다. 파일 하나(`index.html`)로 끝나고, 설치나 회원가입이 필요 없습니다.

## 쓰는 방법

- **웹에서**: https://huhsame.github.io/ggb-0921/
- **내 컴퓨터에서**: `index.html` 파일을 내려받아 더블클릭

## 기능

- 월별 수입·지출·잔액 요약, 화살표로 다른 달 보기
- 월 예산을 정하면 사용률과 남은 금액 표시
- 내역 추가·수정·삭제, 삭제 직후 되돌리기
- 날짜별 묶음 목록, 지출/수입 필터와 메모·분류 검색
- 분류별 지출 비중
- JSON 백업 저장·불러오기, 엑셀용 CSV 내보내기
- 폰 화면 지원, 달밤/한지(낮) 테마 전환
- 한가위 테마 연출: 보름달과 달토끼, 청사초롱, 떨어지는 단풍, 별똥별, 한가위 D-day, 내역 추가 때 엽전·송편 폭죽 (시스템의 ‘동작 줄이기’ 설정을 켜면 애니메이션이 꺼져요)

## 내역은 어디에 저장되나요

내역과 월 예산은 **Supabase 데이터베이스**(프로젝트 `ggb-0921`)에 저장됩니다. 같은 주소로 열면 어느 기기에서든 같은 내역이 보이고, 브라우저의 캐시나 사이트 데이터를 지워도 사라지지 않습니다.

> **주의: 로그인이 없습니다.** 웹페이지 주소를 아는 사람은 누구나 내역을 보고 고치거나 지울 수 있어요. (페이지에 들어 있는 공개용 키로 DB에 접속하고, DB는 그 키를 가진 모두에게 열려 있습니다.) 남에게 보이면 곤란한 내용은 넣지 마세요.

- 인터넷에 연결돼 있어야 열 수 있습니다.
- 예전 버전이 이 브라우저(localStorage)에 저장해 둔 내역이 있으면, 처음 열 때 데이터베이스로 옮길지 물어봅니다. 옮긴 뒤에도 브라우저의 예전 데이터는 지우지 않습니다.
- 오래 보관하려면 화면 아래 **백업 저장(JSON)** 으로 파일을 받아 두세요. **백업 불러오기** 는 지금 내역을 백업 파일의 내용으로 통째로 바꿉니다.

## 처음 열면 보이는 예시 내역

데이터베이스가 비어 있으면 화면 구성을 보여주려고 `예시` 표시가 붙은 샘플 내역이 자동으로 들어갑니다. 목록 위의 **예시 지우고 시작** 버튼으로 한 번에 지울 수 있습니다.
