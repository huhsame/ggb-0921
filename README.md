# 가계부

브라우저에서 바로 쓰는 1인용 가계부입니다. 파일 하나(`index.html`)로 끝나고, 설치나 회원가입이 필요 없습니다.

## 쓰는 방법

- **웹에서**: https://huhsame.github.io/ggb-0921/
- **내 컴퓨터에서**: `index.html` 파일을 내려받아 더블클릭

## 기능

- 월별 수입·지출·잔액 요약, 화살표로 다른 달 보기
- 월 예산을 정하면 사용률과 남은 금액 표시
- 내역 추가·수정·삭제, 삭제 직후 되돌리기
- 날짜별 묶음 목록, 지출/수입 필터와 메모·분류 검색
- 분류별 지출 비중
- JSON 백업 저장·불러오기, 엑셀용 CSV 내보내기
- 폰 화면과 다크 모드 지원

## 내역은 어디에 저장되나요

입력한 내역은 **그 브라우저 안에만** 저장됩니다(localStorage). 서버로 전송되지 않으니 저장소를 공개해도 내 지출이 남에게 보이지 않습니다.

대신 다음 경우에는 내역이 사라집니다.

- 브라우저의 캐시나 사이트 데이터를 지웠을 때
- 시크릿 모드로 열었을 때
- 다른 기기나 다른 브라우저에서 열었을 때

기기를 옮기거나 오래 보관하려면 화면 아래 **백업 저장(JSON)** 으로 파일을 받아 두고, 새 기기에서 **백업 불러오기** 로 옮기세요.

## 처음 열면 보이는 예시 내역

화면 구성을 보여주려고 `예시` 표시가 붙은 샘플 내역이 들어 있습니다. 목록 위의 **예시 지우고 시작** 버튼으로 한 번에 지울 수 있습니다.
